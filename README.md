# Yishi-2
經典是對照，不是教條：一段轉行如何把「反者道之動」走成現實，同時看「菩薩畏因眾生畏果」真義


經典是對照，不是教條：一段轉行如何把「反者道之動」走成現實經典無論出自哪個流派，核心多半離不開因與果。
世人卻常只在「果」上恐懼或後悔，很少在「因」上用力。
《道德經》有「反者道之動」。這句我沒系統從書本學來，是人生反覆演給我看的。對照「菩薩畏因，眾生畏果」，方向一致：
一個從動勢說，一個從心態說。31 歲，我離開餐飲，進入公關行銷與設計。從零開始，進公司先掃地。
工程部時期常背黑鍋；最忙月份幾乎只休一天，白天雜務、晚上進場。公司有給加班費，汗水沒有白流。
關鍵一幕在世貿一館 WiMAX 展。我已具備木工、水電、鐵工、大圖等現場能力。
空檔看見一人穿著整齊、背雙肩包，拿資料與工頭對接。副主管說：那是設計師。

我當下只有一個念頭——我也要成為那樣的人。

之後，我利用工作空檔向設計部了解真實門檻；存錢學 3Ds MAX，半年練熟，並自學平面兩大軟體。從動念到正式任職設計師，約兩年半。其間曾自修法律應考高考，差不到兩分；因經濟現實，轉回設計路徑，後來離開產業時已是經營者。

這段路讓我看清：

「眾生畏果」是事發後才怕、才悔；

「菩薩畏因」是看見目標時，肯把眼前的苦活、學習、紀律當成必種的因。

「反者道之動」不是玄談——往低處走的磨練，若因種得實，會成為推向高處的動力。

低谷時若只抱怨，反轉不會自動發生。
經典是前人記錄的規律，不是要人跪著背的教條。你活得夠用心，生活本身就會把同樣的規律再演示一遍。
你的經歷與文字，也可以成為後來者的對照，而不是另一套要人膜拜的權威。過去有人把規律寫進書裡。

現在有人用自己的時間軸，把它再走一次、再寫一次。
用心過生活，可以跟古人比肩——比的不是名號，是是否把「因」種在能驗證的行動裡。

—— 張枍／來者何枍，台灣
